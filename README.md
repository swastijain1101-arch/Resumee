UPLOAD TO GITHUB PAGES
1. Download and extract this ZIP.
2. Open your existing GitHub repository.
3. Upload index.html and style.css to the repository root.
4. Upload the entire assets folder, preserving its name and contents.
5. Replace the old index.html and style.css when GitHub asks.
6. Commit the changes and wait for GitHub Pages to publish.
